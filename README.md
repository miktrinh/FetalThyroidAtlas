# FetalThyroidAtlas
---
This repository contains all relevant scripts used to process raw sequencing data, perform analyses and generate figures as found in [Massalha, *et al.*, 2024 preprint](https://www.biorxiv.org/content/10.1101/2024.08.22.609152v1)


<br>To run scripts:
```
# Clone the repo
git clone git@github.com:miktrinh/FetalThyroidAtlas.git
cd FetalThyroidAtlas
Rscript R/PTC_snRNAseq/02_pThyCancer_snPreprocessing.R
```
